# mise. web application

This is the Next.js and TypeScript user interface for the meal planner. Setup, configuration, API behavior, limitations, and validation instructions are in the [project README](../README.md).

Run `pnpm install`, set `NEXT_PUBLIC_API_URL` to the FastAPI origin, then run `pnpm dev`. Production output is checked with `pnpm build` (Webpack) and types with `pnpm typecheck`.
